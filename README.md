# 🚀 DevEvent

DevEvent is a platform for discovering developer conferences, hackathons, and tech meetups — all in one place.

## ✨ Features

- 🌍 Discover developer events
- 📅 Explore upcoming developer conferences, hackathons, and meetups
- 📍 Browse events by location
- 🎨 Clean and responsive UI
- 📱 Mobile-friendly design

## 🛠️ Built With

- Next.js
- TypeScript
- React
- Tailwind CSS
